# Informe técnico

| Archivo | Qué es |
|---|---|
| `informe.pdf` | El informe para entregar (8 páginas, el enunciado permite hasta 10) |
| `informe.docx` | El mismo informe en Word, por si hay que editarlo |
| `capturas/` | Capturas de la interfaz Streamlit con el modelo real (11 de octubre de 2026) |

El informe se escribe en un documento en línea:
https://claude.ai/code/artifact/e12b9428-128a-48f9-b61a-e0f949d8202f

El PDF y el Word se generan exportando ese documento a Word y ajustando el formato (letra de
10,5 puntos, márgenes de 2 cm). Con el formato por defecto de la exportación ocupa 13 páginas.
