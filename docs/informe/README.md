# Informe técnico

| Archivo | Qué es |
|---|---|
| `informe.pdf` | El informe para entregar (10 páginas con portada, el enunciado permite hasta 10) |
| `informe.docx` | El mismo informe en Word. Es la versión que se edita: tiene la portada |
| `capturas/` | Capturas de la interfaz Streamlit con el modelo real (11 de octubre de 2026) y de una traza de LangSmith |

El PDF se exporta desde el Word.
